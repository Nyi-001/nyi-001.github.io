Hello, world — launching this site

2026-10-04 sh1n0b1Xby73 · meta · 3 min read

This site is live. It's my public lab notebook: writeups, certifications, solving notes, and the tools I build — all in one place, served straight from github.com via GitHub Pages.

Why a public portfolio?

Security is a field where the work speaks. Certifications open doors, but writeups and working code prove you can walk through them. Everything I solve, I document here — for my future self, and for anyone else walking the same path.

If it's worth learning, it's worth writing down.

How posts get published

Every post is just an HTML file in the blog/ folder. The workflow:

cp blog/hello-world.html blog/my-new-post.html   # copy the template
# edit the title, date and body
# add the card to index.html (section id="writeups")
git add . && git commit -m "blog: new post" && git push

Push it, wait about a minute, and it's live. No build step, no CMS, no database — just files. Exactly how I like it.
